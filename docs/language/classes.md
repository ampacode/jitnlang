# Классы

```nlang
class Person
    public int age = 0
    public string name = "none"
    private int secret = 7

    public Person(int a)        # конструктор — имя = имя класса
        age = a

    public int getAge()         # метод
        return age              # поля доступны по имени

    public void setName(string n)
        name = n

Person p = Person(30)           # создание — вызов имени класса
Empty e                         # объявление типа = конструктор по умолчанию
p.age = 31                      # поля публичные — прямой доступ
print(p.getAge())
```

## Как это работает в двух режимах

**Скомпилированный путь** — прямой перевод: nlang-класс печатается
как C++ `class` с `public:`/`private:`/`protected:` секциями,
конструктор — как `Person(int a)` без типа возврата, `static`
— как `static`-члены. Ноль накладных расходов.

**Интерпретатор (`--eval`)** — класс это «шаблон словаря»:
`Person(30)` создаёт `dict` с полями и методами. Метод — функция
с `bound_self` = экземпляр: при вызове поля экземпляра
прокидываются в область видимости как обычные переменные,
а после возврата пишутся обратно в словарь. Поэтому `age = a`
внутри метода меняет поле объекта.

## Ограничения

- Наследования нет (как и в py-версии на текущем этапе)
- `static` работает в cpp-пути; в eval статика ведёт себя
  как обычное поле
- eval-объекты — словари: `p["age"]` и `p.age` эквивалентны
